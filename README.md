Этот проект представляет собой ассемблер для Учебной Вычислительной Машины (вариант 7). Он преобразует текстовое описание программы на алгебраическом языке в бинарный машинный код, совместимый с архитектурой УВМ. Программа поддерживает четыре типа команд: `LOAD_INDIRECT`, `BSWAP`, `STORE` и `LOAD_CONST`.
Установка и запуск

1. Клонируйте репозиторий (если применимо)
```bash
git clone https://github.com/ваш-репозиторий
cd ваш-репозиторий
```

2. Установите зависимости
Для работы требуется Python 3.7 или выше. Дополнительные зависимости не требуются.

3. Запуск ассемблера
```bash
python assembler.py <исходный_файл> <выходной_файл> [--test]
```

Пример использования:
```bash
python assembler.py program.txt program.bin --test
```
Описание командной строки

| Аргумент      | Описание |
|---------------|----------|
| `source`      | Путь к исходному файлу с текстом программы |
| `output`      | Путь к бинарному файлу-результату |
| `--test`      | Опциональный флаг для вывода байтов каждой инструкции в удобочитаемом виде |

Поддерживаемые инструкции

Программа понимает следующие конструкции:

| Инструкция        | Формат в коде                     | Описание |
|-------------------|-----------------------------------|----------|
| `LOAD_INDIRECT`   | `mem[C] = mem[mem[B]]`           | Косвенная загрузка |
| `BSWAP`           | `mem[C] = bswap(mem[B])`         | Байтовый своп |
| `STORE`           | `mem[C] = mem[B]`                | Прямое копирование |
| `LOAD_CONST`      | `mem[B] = C`                     | Загрузка константы |

Комментарии начинаются с символа `#` и игнорируются.
Пример исходного файла

```asm
# Пример программы
mem[1] = 42          # LOAD_CONST
mem[2] = mem[1]      # STORE
mem[3] = bswap(mem[2]) # BSWAP
mem[4] = mem[mem[3]]   # LOAD_INDIRECT
```

Пример вывода в тестовом режиме

```bash
python assembler.py example.txt example.bin --test
```

Вывод:
```
Размер двоичного файла: 28 байт
1: 0x07, 0x00, 0x00, 0x00, 0x2A, 0x00, 0x00
2: 0x0D, 0x04, 0x00, 0x00, 0x00, 0x00, 0x00
3: 0x03, 0x08, 0x00, 0x00, 0x00, 0x00, 0x00
4: 0x01, 0x0C, 0x00, 0x00, 0x00, 0x00, 0x00
```

Как это работает

1. Парсинг исходного кода — каждая строка анализируется с помощью регулярных выражений.
2. Построение промежуточного представления (IR) — создаётся список объектов `Instruction`.
3. Кодирование в машинный код — каждая инструкция упаковывается в 7-байтовое слово в формате little-endian.
4. Запись бинарного файла — полученные байты сохраняются в выходной файл.

Обработка ошибок

- При синтаксической ошибке в исходном коде выводится сообщение с номером строки.
- При выходе значений за допустимые диапазоны генерируется `ValueError`.
- Неправильные имена файлов или пути обрабатываются стандартными средствами Python.
